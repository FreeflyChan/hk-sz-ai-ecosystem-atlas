# 港深 AI 创业地图 · AI4S × 具身智能

一张可以点开的交互式地图，把**香港与深圳**两地 30 家 AI4S（AI for Science，用 AI 做科研）与具身智能（机器人）创业公司、61 个产业资源节点放在同一个坐标系里，用来回答三个问题：

- 谁在哪里、做什么、团队什么背景？
- 两座城市的产业资源分别强在哪、缺在哪？
- 一个投资人站在 2026 年 11 月，应该先看哪几条线？

> 语言上尽量不用行话：页面里出现的每个概念都配了大白话解释，目标是让非理工背景的读者也能看懂并复述。

## 页面包含什么

| 模块 | 内容 | 你可以怎么用 |
| --- | --- | --- |
| 创业地图 | Leaflet 交互地图，公司按赛道着色、按片区分组聚合；园区、高校、投资机构、政策分层展示 | 点公司看详情，点聚合泡展开，鼠标悬停看一句话介绍 |

## 目录结构

```
hk-sz-ai-atlas/
├── index.html              # 页面结构（语义化 HTML，无框架、无构建）
├── assets/
│   ├── css/
│   │   └── main.css        # 设计令牌 + 全部样式（含响应式）
│   └── js/
│       ├── data.js         # 唯一数据源：公司 / 生态节点 / 结论
│       ├── map.js          # 地图渲染、筛选联动、详情抽屉
│       └── charts.js       # 三张图表 + 十条结论渲染
└── README.md
```

技术栈刻意保持简单：**纯静态单页**，不依赖 Node、不需要打包。外部只引三个 CDN 资源：

- Leaflet 1.9.4（地图）
- Leaflet.markercluster 1.5.3（点位聚合）
- Chart.js 4.4.1（图表）

底图使用 OpenStreetMap，并用 CSS 滤镜压成浅灰，避免彩色底图抢走数据点的注意力。

## 数据说明

### 公司口径

- 收录**以 AI 为核心方法**的创业公司，不包含大型互联网公司与传统制造企业。
- 覆盖两个赛道：
  - **AI4S**：AI 制药、蛋白质设计、合成生物、基因测序、实验室自动化、量子计算等。
  - **具身智能**：人形机器人、四足机器人、灵巧手与触觉、机器人「大脑」与运动控制。
- 每家公司包含：核心业务方向、技术产品定位、创始人及核心团队背景、融资阶段与最新进展、投资看点、信息来源。

### 生态节点口径

61 个节点分为五类，可在地图右上角逐层开关：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| 园区 / 基地 | 产业空间载体 | 深圳南山智园、香港科学园 |
| 高校 / 实验室 | 源头科研能力 | 香港大学、香港科技大学、中科院深圳先进院 |
| 投资机构 | 谁在出钱 | 深创投、HKSTP Venture、启明创投 |
| 扶持政策 | 政府支持工具 | 深圳「20+8」产业集群、香港 ITF 基金 |
| 产业片区 | 聚集区范围（默认关闭） | 南山机器人谷、河套深港科技创新合作区 |

### 坐标与可信度

- 公司不公开精确门牌，坐标为**所在片区的近似点**，并在同一片区做了轻微螺旋偏移，避免点位完全重叠。地图用于观察**空间聚集关系**，不能当作办公地址使用。
- 每条公司数据标注了信息可信度：
  - `高`：官网、交易所披露等可核验来源；
  - `中`：来自公开报道，建议使用前二次核对。
- 融资信息截止 **2026 年 11 月**，未披露金额统一标注「未披露」，不做估算。

## 如何更新数据

所有内容集中在一个文件里：`assets/js/data.js`。

```js
window.SITE_DATA = {
  meta:      { title, subtitle, updated, note },
  companies: [ { id, name, nameEn, city, district, domain, sub,
                 stage, stageGroup, funding, founders[], positioning,
                 why, site, source, confidence, note?, lat, lng } ],
  nodes:     [ { id, type, name, city, district, lat, lng, desc, tags[], source } ],
  insights:  [ { n, t, d } ]
};
```

新增一家公司 = 往 `companies` 数组里加一个对象；筛选器、列表、地图、图表会自动更新，不需要改其它代码。

## 部署到 GitHub Pages

本仓库可按以下方式发布（无构建产物，直接托管静态文件）：

1. 将代码推到 `main` 分支；
2. 仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`；
3. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

也可以用命令行：

```bash
gh api -X POST repos/{owner}/{repo}/pages \
  -f 'source[branch]=main' -f 'source[path]=/'
```
